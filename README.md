1. Jelaskan apa itu Bootstrap dan apa kegunaannya!
--> Bootstrap adalah framework front‑end berbasis HTML, CSS, dan JavaScript yang menyediakan komponen siap pakai (seperti tombol, form, navbar, grid, dll). Kegunaan Bootstrap yaitu memudahkan developer membuat website yang/konsep website yang diinginkan tanpa membuat codingan dari 0/lebih ke desain dari 0

2. Ada beberapa cara untuk mengimpor atau menggunakan Bootstrap pada project. Sebutkan cara caranya!
--> Cara pertama dan yang paling umum digunakan yaitu dengan memanggil link CSS dan JS Bootstrap di <head> HTML dengan  CDN (Content Delivery Network). Kemudian cara keduanya yaitu dengan menyimpan file CSS/JS di project(jadi file bootstrapnya di download), lalu nantinya dipanggil secara lokal.

3. Jelaskan mengenai class grid dan kegunaan breakpoint!
--> Grid adalah sistem layout berbasis 12 kolom. Dengan grid, halmaan bisa dibagi menjadi beberapa bagian menggunakan class seperti col-, col-sm-, col-md-, col-lg-, dan col-xl- dan untuk breakpoint adalah ukuran lebar layar tertentu di mana layout akan berubah. Misalnya: col-sm-6 di layar kecil (≥576px) elemen mengambil 6 kolom.
   
4. Sebutkan minimal lima class yang disediakan oleh Bootstrap beserta kegunaannya!
   - btn btn-success(membuat tombol hijau)
   - table table-stripped(membuat tabel dengan garis zebra)
   - text-center(membuat teks rata tengah)
   - form-control(membuat styling input form)
   - navbar navbar-dark bg-success(membuat navbar gelap dengan background hijau)
